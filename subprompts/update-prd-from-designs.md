# Update PRD from Designs

Read and follow `ai-framework/03b-update-prd-from-designs.md`.

Sync the PRD with the finalized design catalog so the PRD stays the single source of truth for execution and validation.

## When to use

- After `/design` or `/design-with-v0` is complete for a phase.
- Before `/execute-plan`.

## Your process

1. **Get inputs.** Ask:
   - Which PRD? (e.g. `@~/Desktop/Resources/PDLC Workflow Docs/[feature-name]/prd/[feature-name]-prd.md`)
   - Which design catalog? (e.g. `@~/Desktop/Resources/PDLC Workflow Docs/[feature-name]/design/[feature-name]-phase-1-designs.md`)
   - If not provided, check `~/Desktop/Resources/PDLC Workflow Docs/[feature-name]/design/` for the most recent catalog and confirm.

2. **Follow the framework file.** Read `ai-framework/03b-update-prd-from-designs.md` and apply all updates: design catalog reference, copy/flow changes, acceptance criteria, decision log, frontend task list.

3. **Save and confirm.** Save the PRD. State:
   - "PRD updated for Phase [N] from design catalog [path]. Ready for `/execute-plan`."
